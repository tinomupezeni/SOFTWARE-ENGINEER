# Change History

One file per session/change that altered architecture or decisions, named
`YYYY-MM-DD-brief-summary.md`. Not a diary of every commit — only entries
that would otherwise force a re-read of git history to understand "how did
we get here." Each entry: what changed, why, and which `architecture/` or
`decisions/` files were updated as a result (update those files too — this
log doesn't replace them).
