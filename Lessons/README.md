# Lessons in Software Engineering

A centralized repository for high-level architectural insights, engineering principles, and lessons learned through AI-orchestrated development.

## Quick Reference

- [Engineering Principles Cheat Sheet](./CHEAT_SHEET.md) - Plain-language, memorize-these version of the recurring lessons pulled from this repo's dev-logs. Start here.
- Full technical detail, stack-specific rules, and checklists live in
  [`../Principal_Engineer/engineering-guides/`](../Principal_Engineer/engineering-guides/MANIFEST.md).

## Not here: project-specific planning docs

This folder holds *general*, cross-project lessons only. A single
project's own ADRs, procedural workflow docs, or planning notes belong in
*that project's own repo* — not here. (An earlier `planning/` subfolder
here was a stray duplicate of content that already lives correctly in one
such project's repo; it's been removed.)

## Core Philosophies
1. **The Scientific Method:** Formulate hypotheses before acting.
2. **Reverse Engineering Era:** Learn by challenging AI-generated systems.
3. **Complexity over Syntax:** Measure growth by systems managed, not lines typed.
